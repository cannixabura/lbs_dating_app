# 送禮與糾纏款

> 決定：2026-11-07（使用者）。伺服器規則在 `geo-service/gifts.js`，端點 `exports.gifts`，App 在 `lib/gifts/gifts.dart`。

## 1. 禮物種類與價格

| 禮物 | 商品代號 | 價格 | 收下後 |
|---|---|---|---|
| 光之花束 | `gift_bouquet` | NT$30 | 畫面綻開一束光粒子花；之後 24 小時對方的光球旁有一圈花瓣光點，量子世界裡附近的人都看得到 |
| 送一款光球 | `gift_orb` | NT$90 | 送的人挑款式（目前販售中的付費款式），對方永久擁有 |
| 糾纏款 | `gift_pair` | NT$90（一組兩顆） | 兩人都得到糾纏款光球並配成一對；兩人都在量子世界時有一條金、粉兩股的光繩相連（不管多遠） |

- 價格規則：消耗性 NT$30、非消耗性 NT$90。
- 商店上**一律是消耗性商品**：非消耗性商品每個帳號只能買一次，就不能送第二個人。對方收下後，伺服器再把款式記到對方帳號（`orbOwned/{uid}/{style}`，`src: 'gift'`）。
- 糾纏款光球（`pair`）只能透過糾纏款禮物取得，不是免費款、不能直接買；量化身面板只有擁有的人看得到。

## 2. 流程

1. 在地圖、量子世界的點人選單，或聊天畫面頂部點「送禮物」（不用先加好友；示範對象、殘影不能送）。
2. 選禮物 → 商店付款 → App 把收據和對象送到伺服器 `send`。App 付款前先把對象存在手機上，中途被關掉時，沒有對象的禮物會變成禮券。
3. 伺服器驗證收據（同一筆購買只算一份），檢查對方收不收得到：
   - 封鎖（任一方）、對方關掉「接收禮物」、對方已經有這款光球、任一方已經有糾纏款配對 → **退回給送的人**，變成禮券。
4. 對方收到推播，打開 App 會跳出收禮清單：**收下**或**婉拒**。
5. 婉拒、7 天沒回應（每天 05:00 的 `expireGifts` 會檢查）→ 退回給送的人變成禮券，推播通知。
6. 禮券在送禮選單上方「退回的禮物（不用再付錢）」可以直接送給別人。

## 3. 其他

- 設定 →「禮物」：收到的禮物、接收禮物開關（預設開）、退回的禮物份數、解除糾纏款配對（兩人都保留光球，只是不再有光繩）。
- 退款：還沒收下的禮物、禮券取消；已收下的光球款式從對方帳號移除；花束、配對不追回。Apple 走 App Store 伺服器通知，Google 走每天的 voidedpurchases。
- 刪除帳號：收到還沒回覆的禮物退回給送的人；自己送出或收到的送禮紀錄刪除；配對解除。
- 隱私：只記誰送給誰、哪種禮物、時間與結果；收禮的人看得到送禮人的暱稱。

## 4. 資料

Realtime Database（只有伺服器讀寫）：`gifts/{id}`、`giftInbox/{uid}/{id}`、`giftVouchers/{uid}/{id}`、`giftPending/{id}`、`giftReceipts/{receipt}`、`giftPrefs/{uid}`、`orbPair/{uid}`、`giftBouquet/{uid}`。

Redis：`orb_pair:{uid}`（量子世界心跳畫光繩）、`gift_bouquet:{uid}`（花束還在時存在，自動到期）。
