# ChatBubble

Messages in a 10-minute chat: theirs on `night-700` glass at the left, yours on the deep gradient at the right, under a glass header with the countdown and a 檢舉 button.

- Provide the messages, the other person's name and avatar, the remaining time, and the report handler.
- The header's flag button opens ReportSheet; it is required by App Store guideline 1.2.
- Show the sender name above their first message in a run only.
- Message text uses `body`; long words wrap inside the bubble.
