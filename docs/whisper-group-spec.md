# 低語團規格

2026-11-06 定稿。一般集會（`geo-service/gathering.js`、`lib/gathering.dart`）是「附近 5 公里、自願加入的陌生人」；**低語團是私人的團體**：只有拿到團主 QR code 的人才能加入，外人看不到、也無法搜尋或申請。用途不限於導遊帶團：旅行團、校外教學、登山社、公司旅遊、親友出遊、活動工作人員都能用。兩者分開實作，共用公告、檢舉、內容過濾。

稱呼：帶團的人叫**團主**，其他人叫**團員**。

## 1. 已決定

| 項目 | 決定 |
|---|---|
| 入團方式 | 團主出示 QR code，團員掃描入團；不限距離；行程結束自動解散 |
| 隱私 | 私人團體：只能用團主的 QR code 或分享連結加入，不公開、不可搜尋 |
| 人數與收費 | 20 人以內免費；第 21 人起要買「低語團 7 天方案」NT$290 |
| 上限 | 付費後最多 100 人 |
| 計價單位 | 每團每次 7 天；團員（一般使用者）永遠免費 |
| 第一版 | QR 入團、集合呼叫、點名、集合點光柱 |
| 第二版 | 光之團旗、我迷路了（11/7 完成：團旗是本機全螢幕閃爍團色＋團號；我迷路了傳一次位置、30 分鐘後刪除，團主收到提醒、名單、地圖紅色圖釘與導航） |
| iOS 提醒 | 時效性通知（Time Sensitive），不申請 Critical Alerts |
| Android 提醒 | 高優先通知＋自訂震動與音效的專屬通知頻道 |
| 入口 | 設定 →「集會」區 →「開一個低語團」。開團後或入團後，地圖下方人物圖示旁才出現低語團按鈕；團主和團員看到不同的操作 |

## 2. 角色與生命週期

- **團主**：設定 →「開一個低語團」。填團名（20 字內）、團色（8 色擇一）、行程日期（最長 7 天）。一個人同時只能帶一團。
- **團員**：掃 QR code（或點分享連結）→ 確認團名與團主暱稱 → 入團。同時只能在一個團。
- **團號**：入團順序自動編號 1、2、3…，團主可以改備註（例如「王小明」）。備註只有團主看得到。
- **結束**：行程結束日 23:59（台北時間）自動解散；團主可以提早解散。解散後團員名單、點名紀錄、集合點全部刪除。
- **離團**：團員隨時可以退出；團主可以移除團員。
- **交棒**：沿用集會的主持人交棒流程，交給團裡的另一位成員（例如副領隊）。

### QR code
- 內容：`https://mood-whisper-f7de9.web.app/g/<團代碼>`；團代碼 8 碼英數，無法猜測。
- 已安裝 App：開啟 App 直接到入團確認畫面（Universal Link／App Link）。
- 沒安裝：網頁顯示團名與下載連結。
- 團主可以「換新 QR code」，舊的立即失效（防止外流）。

## 3. 集合呼叫

1. 團主按「集合」→ 選集合時間（現在／10／15／30 分鐘後／自訂）→ 確認集合點（預設是團主目前打卡的位置，可以在地圖上拖曳）→ 送出。
2. **團員手機**
   - 推播：標題「🟣 {團名} 集合」，內文「15:30 到 {集合點說明}，還有 15 分鐘」。
   - iOS：`interruption-level: time-sensitive`，穿透專注模式；專屬提示音（3 秒內，打包在 App 裡）。
   - Android：通知頻道「低語團集合」，`IMPORTANCE_HIGH`，專屬音效＋震動節奏「短 短 長」（0, 150, 100, 150, 100, 600 ms）。使用者可以在系統設定裡調整這個頻道。
   - App 在前景：全螢幕卡片（集合點、倒數、距離與方向箭頭）＋同樣的震動，一顆大按鈕「收到」。
3. **沒按「收到」的人**：每 60 秒再推一次，最多 3 次；集合時間到了就停。
4. **團主的名單**
   - ✅ 收到　👀 打開了沒回　⚪ 沒反應（依沒反應→打開沒回→收到排序）
   - 上方統計「收到 18／20」。
5. **集合時間前 5 分鐘**：自動提醒一次還沒「我到了」的人（點名的狀態，見下節）。

## 4. 點名

- 團主按「點名」→ 團員收到和集合呼叫一樣的提醒（iOS 時效性通知＋專屬音效、Android `group_call` 頻道＋「短 短 長」震動，不重複響），App 開著時跳出全螢幕點名卡片並震動，三個大按鈕：
  - **我到了**
  - **還要 5 分鐘**
  - **需要幫忙**（團主端以紅色標示並置頂）
- 團主畫面即時統計「到了 17／20」，沒回的人排最上面，點一下可以「單獨呼叫」（只對這個人重新推送集合呼叫）。
- 集合呼叫和點名可以同時進行：集合呼叫裡的「收到」不等於「我到了」。

## 5. 集合點光柱

- 團員地圖上出現團色的光柱、距離（例如「320m」），以及指向集合點的方向箭頭（用手機自己的位置和指南針在手機上算，**不把團員位置傳給任何人**）。
- 集合點有一行說明（30 字內，例如「捷運西門站 6 號出口」）。
- 集合結束（團主按「人齊了」或集合時間過 30 分鐘）光柱消失。

## 6. 隱私與 Apple 5.1.2(i)

- **團員的位置不會給團主**。團主只看得到團員的回覆狀態（收到／到了…），看不到團員在哪裡。
- 團員出現在一般雷達上的規則不變：要自己打卡、要先同意「在地圖上顯示你的位置」。入團不等於打卡。
- 第二版的「我迷路了」：只有團員自己按下時，才把**當下位置送一次**給團主；每次都要自己按，不會持續追蹤；團主端 30 分鐘後自動消失。
- 推播內容不含任何位置座標，只有團主寫的集合點說明。
- 團員名單、點名紀錄只存在團存續期間，解散即刪除。

## 7. 收費（低語團 7 天方案）

- 20 人以內（含團主）：免費，所有功能都能用。
- 第 21 位要入團時，若團主還沒買方案：團員端顯示「這個團已滿」，團主端提示購買。
- **商品**：`group_pass_7d`，iOS 用「非續訂型訂閱」或「消耗型」（建議消耗型：一次購買＝一團 7 天，買了立即生效，不自動續費）；Android 一次性產品。
- 生效：從購買當下起 7 天（或到行程結束日，取較晚者，但最長 7 天）；人數上限提高到 **100 人**。
- 一次購買只能用在一個團；團提早解散不退費（條款要寫清楚，退款依 Apple／Google 流程）。
- **價格：NT$290／團／7 天**（其他地區由商店依匯率換算）。

## 8. 技術做法

### 伺服器（新檔 `geo-service/whispergroup.js` ＋ `exports.whisperGroup`）
- **Redis**
  - `wgroup:{code}`：團資料（團主 uid、團名、團色、結束時間、pass 到期）；TTL 到結束時間＋1 天
  - `wgroup_members:{code}`：hash，uid → 團號、備註、加入時間
  - `wgroup_of:{uid}`：使用者目前所在的團
  - `wgroup_call:{code}`：目前的集合呼叫（集合點、時間、說明）
  - `wgroup_acks:{code}:{callId}`：hash，uid → `seen` / `ack`
  - `wgroup_roll:{code}:{rollId}`：hash，uid → `here` / `5min` / `help`
- **動作**：`create` / `join` / `leave` / `kick` / `rotate_qr` / `call` / `ack` / `seen` / `rollcall` / `answer` / `gather_done` / `dissolve` / `handoff` / `status` / `verify`（購買）
- **重複提醒**：Cloud Tasks 或排程 function 每分鐘掃描未回應名單、重送，最多 3 次。
- **推播**：沿用 FCM（`tokens/{uid}`）。iOS 加 `apns.headers["apns-push-type"]="alert"`、`payload.aps["interruption-level"]="time-sensitive"`、`sound="group_call.caf"`；Android `android.priority="high"`、`notification.channel_id="group_call"`。
- **內容過濾**：團名、集合點說明、備註走 `contentfilter`。

### App
- 新檔 `lib/whisper_group/`：建立團、QR code（`qr_flutter`）、掃描（`mobile_scanner`）、團員名單、集合呼叫卡片、點名卡片、集合點光柱（畫在雷達上，沿用集會的光環繪製）。
- iOS：Xcode 開啟 **Time Sensitive Notifications** capability（只要勾選，不需向 Apple 申請）；音效檔 `group_call.caf` 放進 Runner。
- Android：App 啟動時建立通知頻道 `group_call`（`flutter_local_notifications`），設定音效與震動節奏。
- Deep link：`/g/<code>` 的 Universal Link（`apple-app-site-association`）與 App Link（`assetlinks.json`），放在 hosting。

### 條款與隱私權
- 條款：低語團方案的計價、7 天效期、一次購買限一團、不退費原則、團主的使用規範（不得用來騷擾或追蹤團員）。
- 隱私權：團員名單、團號、備註、回覆狀態、保存期間（解散即刪）、「我迷路了」只傳一次位置。
- 9 種語言介面文字與操作說明新增一節。

## 9. 開發順序

1. 伺服器 `whispergroup.js`（純函式＋測試）與 `exports.whisperGroup`：建立、入團、QR、集合呼叫、收到、點名、解散。
2. App：建立團與 QR、掃描入團、團員名單。
3. 集合呼叫：推播（iOS 時效性、Android 專屬頻道）、前景卡片、重複提醒、團主名單狀態。
4. 點名與集合點光柱。
5. 20 人上限與 `group_pass_7d` 購買。
6. 條款、隱私權、9 種語言、操作說明、官網；兩台手機實測後送審。

## 10. 入口與操作（11/6 決定）

- **開團**：設定 →「集會」區 →「開一個低語團」。
- **地圖按鈕**：只有在團裡（團主或團員）時，地圖下方人物圖示旁才出現團色的低語團按鈕；不在團裡就不顯示。
- **團主按下**：集合、點名、集合點、團員名單（狀態與備註）、QR code／換新、公告、交棒、解散。
- **團員按下**：目前的集合呼叫與倒數（收到）、點名回覆（我到了／還要 5 分鐘／需要幫忙）、集合點光柱與方向、團資訊（團名、團主、人數）、退出低語團；第二版加「舉旗」與「我迷路了」。
- 有進行中的集合呼叫時，按鈕外圈會閃團色，提醒還沒按「收到」。
