# 城市燈塔：公廁資料調查（2026-10-24）

## 資料來源

- 環境部環境管理署「全國公廁建檔資料」：data.gov.tw 資料集 30794
- 每月更新，最後更新 2026-10-24
- 授權：政府資料開放授權條款第 1 版。免費，可商用，需標示出處。
- API：`https://data.moenv.gov.tw/api/v2/fac_p_07?api_key=<key>&limit=1000&offset=<n>&format=JSON`
  - 必須帶 api_key（沒帶會回「api_key 不存在」）。
  - data.gov.tw 下載連結附的是共用金鑰。正式上線前要到 data.moenv.gov.tw 申請自己的金鑰（免費，需註冊會員）。
- 承辦窗口：陳先生 (04)22521718#53712

## 欄位

| 欄位 | 內容 |
|---|---|
| county / areacode / village | 縣市、鄉鎮、村里代碼與名稱 |
| number | 建檔編號（幾乎唯一：46,006 筆中有 45,706 個不同編號） |
| name / address | 名稱（通常是「場所-廁所種類」）、地址 |
| latitude / longitude | 座標。0 筆壞值，26 筆在台灣範圍外 |
| type | 廁所種類：男、女、無障礙、混合、親子、性別友善、未設定 |
| type2 | 場所類別：商業營業場所、民眾洽公場所、交通、公園等 10 類 |
| grade | 特優級 44,250、優等級 1,255、普通級 244、不合格 257 |
| diaper | 尿布檯數量（4,570 筆 ≥ 1） |

**沒有開放時間。**

## 數量

資料共 46,006 筆。一筆是「一間廁所」，同一棟建築會拆成很多筆。依座標合併後是 24,206 個地點。

| 種類 | 筆數 | 地點數 |
|---|---|---|
| 無障礙廁所 | 7,394 | 5,871 |
| 親子廁所 | 1,373 | 1,108 |
| 性別友善廁所 | 886 | 773 |
| 有尿布檯（任何種類） | 4,570 | 3,257 |
| 上述任一 | — | 8,253 |

性別友善廁所的縣市分布：

- 台中 125、台北 117、桃園 116、新北 95、台南 82。
- 有些縣市是 0 到 4 筆。

範例：台北 101 周邊 400 公尺內查得到 101 購物中心 B1（性別友善＋無障礙＋親子）、捷運台北 101 世貿站、信義運動中心等，座標準確到建築物。

## 品質與限制

1. **性別友善的定義不一。** 伴侶盟 2024 年實地查核 149 間，只有 54 間符合基本原則。App 裡要寫「依政府登錄資料」，並提供「回報這間不符」。
2. **沒有開放時間，但 App 是晚上用的。** 性別友善廁所有 242 間在「民眾洽公場所」（區公所、戶政事務所），晚上多半沒開。
   - 名稱含捷運、車站、公園、加油站、超商的：性別友善 146 間、無障礙 1,699 間、親子 390 間，可能 24 小時開放。
   - 可以用 type2 和名稱推估「晚上可能有開」，但只能標成推估。
3. **一棟樓很多筆。** 最多一個座標有 170 筆（板橋車站）。地圖上要先合併成一個地點，再列出樓層和種類。
4. **不合格 257 筆。** 預設不顯示。
