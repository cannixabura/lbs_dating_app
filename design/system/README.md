城市低語是一座夜裡的城市：深藍紫的天、灰藍綠的微光道路，和浮在建築之間、會呼吸的心情氣泡。整套介面只有一個主題「夜」，所有畫面都從 `night-900` 開始往上疊。

## 語氣與文字

- 對使用者說「你」，對對方說「對方」或對方的城市稱呼。不用「用戶」「會員」。
- 句子短、安靜、帶一點詩意，但動作要清楚：按鈕寫它會做的事（「走進城市低語」「送出檢舉」），不寫「確定」。
- 不用驚嘆號，不用表情符號當裝飾。表情符號只出現在使用者自己寫的心情與暱稱裡。
- 拒絕、冷卻、錯誤都用溫和的說法，但要說清楚原因與下一步。實際文案：
  - 「對方目前不想被打擾，請給彼此一點空間。」
  - 「這只是一道歷史殘影，無法產生交集。」
  - 「敲門沒有送出，請稍後再試。」
- 狀態詞固定用：活躍、休息中、歷史殘影、敲門中、冷卻中。

## 色彩

- 背景一律 `night-900`；地圖地面與聊天室用 `night-800`；輸入框、列表列用 `night-700`。不再使用中性灰 `#121212`。
- 主要文字 `ink`，次要 `ink-muted`，說明文字 `ink-faint`。`ink-faint` 只用在 caption 大小，且只放在 `night-700` 或更深的底上。
- 招牌漸層有兩組，不能混用：
  - **亮漸層** `aurora-violet` → `aurora-blue`：標題關鍵字、發光邊框、光暈、焦點框。它上面不放白字（白字只有 2:1～3.9:1）。
  - **深漸層** `deep-violet` → `deep-blue`：按鈕底色、自己的聊天泡泡。上面的字用 `on-deep`。
- 一個畫面只有一個亮漸層的焦點：通常是主按鈕或標題，不是兩者同時。
- 敲門相關一律 `knock-pink`；同意用 `city-amber`；封鎖、檢舉用 `danger`（只用在圖示、文字和 1px 邊框，不當大面積底色）。
- 心情顏色 `mood-*` 只用在 MoodBubble 的邊框、光暈、定位點與漣漪，由心情文字決定，見下方「心情與圖示」。
- 歷史殘影的邊框和圖示用 `shadow-ink`，整顆氣泡的透明度從 `shadow-start` 線性淡到 `shadow-end`。休息中的氣泡用 `resting` 透明度、停止呼吸光暈。

## 地圖

- 地圖樣式內建在 App（`assets/map/night_style.json`），由 `tool/build_night_map_style.py` 從 dark-matter 樣式重新上色；圖資來自 **OpenFreeMap**（OpenMapTiles 格式，免費、可商用、免金鑰）。要調整顏色就改腳本再重新產生。
- 地面 `night-800`，水域 `map-water` 加 `deep-blue` 光邊。
- 道路一律用冷色的 `map-road-*`，依層級由亮到暗：`map-road-major` → `map-road-mid` → `map-road-minor` → `map-road-path`。每條路底下有一層同色、模糊的光暈。**不要用暖色道路**：橘色和暗金都在實機上試過，和深藍紫是互補色，再暗都會跳出來。
- 3D 建築從 `map-building-low` 依高度漸變到 `map-building-high`，只有最高的建築帶一點紫。
- 地圖傾斜時，地平線上方疊一層 `night-900` 到透明的夜空漸層，平放時不顯示。
- 左下角保留「© OpenMapTiles © OpenStreetMap」出處標示（`ink-faint`、10px），這是地圖資料授權的要求。

## 字體

- 全部用 `sans`（Noto Sans TC）。倒數計時用 `numeral`（Chakra Petch），一律等寬數字。
- `display` 只出現在引導頁。標題前兩個字套亮漸層，其餘用 `ink`（引導頁「沒入這座城市」「片刻的交集」的寫法）。
- 卡片標題 `title`，內文 `body`，氣泡裡的心情 `mood`，按鈕 `label`，名字·距離與計數器 `caption`。`caption` 是最小字級，不再更小。
- 尊重系統字級設定：版面要能容納 1.3 倍字級而不截字。

## 玻璃與光

- 浮在地圖上的東西都是玻璃：`glass-fill` 底、1px `glass-line` 邊框、`radius-lg` 圓角、下方 `lift` 陰影。最重要的卡片（敲門、進場）另加 `glow-violet` 光暈。
- **真正的背景模糊只用在靜態的卡片與底部選單**（例如對話框打開時）。地圖上即時移動的氣泡不做模糊，改用半透明加光暈，以免掉幀與耗電。
- 敲門中的氣泡用 `glow-pink` 脈動；其他光暈都是靜止的。

## 形狀與間距

- 畫面左右留白 `space-4`。卡片內距 `space-4`，含表單時 `space-6`。標題區塊和下方卡片之間 `space-8`。
- 圓角：輸入框 `radius-sm`、氣泡與聊天泡泡 `radius-md`、卡片與底部選單 `radius-lg`、按鈕與提示條 `radius-pill`。
- 觸控目標至少 44×44px，按鈕高度 48px。

## 動態

每一種動態都有意義，不做裝飾性的動畫：

- **進場鏡頭**：進入城市時，鏡頭從城市高空（zoom 12、正上方）2.6 秒俯衝到街道並傾斜 50°，夜光地圖從 `night-900` 中亮起；落地後氣泡與底部選單才淡入。
- **氣泡呼吸**：活躍的氣泡，心情色光暈緩慢明暗（2.4 秒來回）。
- **敲門儀式**：等待回音時，`knock-pink` 虛線弧從自己流向對方（0.9 秒一輪），加上倒數條；結束時光在對方位置化成粒子往上散去（1.1 秒）。見 KnockRitual。
- **微光迸發**：送出共鳴時，對方的氣泡迸出心情色的光點（1 秒）。
- **殘影淡出**：歷史殘影的透明度隨留存時間從 `shadow-start` 線性淡到 `shadow-end`。

系統開啟「減少動態效果」時：進場鏡頭直接到位、呼吸與脈動改為靜止光暈、虛線弧不流動、粒子與光點不播放，只保留文字提示。

## 匿名與城市

- **低語**（Whisper）：永遠不顯示作者，也不和雷達上的氣泡連在一起；位置只到 100 公尺範圍；7 天後消散。檢舉低語時沒有封鎖選項。
- **城市心情天氣**（CityMoodWeather）：只顯示 20 公里、24 小時內的匿名比例；**少於 10 人一律不顯示比例**，改說「城市還很安靜」。
- **共鳴**：收到的人只看到「今晚 N 道微光與你共鳴」，永遠不知道是誰送的；同一人 24 小時一次。
- 分享出去的心情卡不放任何位置，只寫「在城市的某個角落」。

## 心情與圖示

- 心情氣泡裡**只有使用者寫的那一句心情**，不加心情圖示。App 還在早期、附近的人不多，讓每一句話被完整看見最重要。
- 氣泡的顏色由 App 依心情文字的關鍵字決定，順序與目前的 App 相同（先符合者優先）：

  | 關鍵字 | 顏色 token |
  | --- | --- |
  | 😊 開心 笑 | `mood-joy` |
  | 😢 難過 哭 | `mood-sad` |
  | 😡 生氣 怒 | `mood-angry` |
  | 🌿 平靜 發呆 | `mood-calm` |
  | 🔥 熱情 | `mood-passion` |
  | 💖 愛 心 | `mood-love` |
  | 其他 | `mood-default` |

- 心情顏色只用在氣泡的邊框、光暈、定位點與地面漣漪；氣泡裡的字一律 `ink`，確保任何顏色下都讀得清楚。
- 介面圖示（設定、封鎖、檢舉、送出、沙漏）用同一套 2px 線條圖示，顏色跟著文字 token。預覽中的圖形是暫用的，正式版建議改用 Material Symbols Rounded 或 Phosphor。

## 上架審核必備流程

這兩個流程是 App Store 與 Google Play 審核的必要條件，任何改版都不能拿掉：

- **檢舉**（ReportSheet）：氣泡的長按選單、敲門卡片、聊天室右上角都要能進入。送出後預設同時封鎖對方。
- **使用條款同意**（EntryCard）：第一次進入前必須勾選同意《使用條款》與《隱私權政策》，並明列「對不當內容零容忍」。未勾選時主按鈕停用。進場只填心情，不填暱稱。

## 無障礙

- 每組文字與背景的對比至少 4.5:1（24px 以上的字 3:1），每個 token 的 usage 都寫明它可以放在哪些底上。
- 焦點框：2px `aurora-violet` 實線、外推 2px，在所有表面上都至少 3:1。
- 狀態不能只靠顏色：休息中有「休息中」字樣，殘影有灰色加上不同的圖示，敲門中有倒數。
