# GradientButton

The one action that moves the person forward, filled with the deep gradient (`deep-violet` to `deep-blue`) and white `on-deep` text.

- Provide a verb label that says what happens (「走進城市低語」「送出檢舉」), and `disabled` until the action is allowed.
- One filled button per screen. Pair it with `cw-btn--ghost` (secondary), `cw-btn--warm` (同意), `cw-btn--danger` (封鎖、檢舉) or `cw-btn--text` (略過).
- Height 48px, pill radius; labels in the `label` style.
- Don't fill a button with the bright `aurora-*` gradient: white text on it falls to 2:1.
